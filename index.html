Git & GitHub workflow

    The main four Area of git and github work flow
  1. working Directory: Your project files are here. you can edit and write code in this directory
  2. Staging Area: You can add your code, project files and any other changes to git
  3. Local Repo: you can make the local version of your remote repository on your local machine
  4. Remote Repository: You can store your project, files or data on an online platform inside repository
